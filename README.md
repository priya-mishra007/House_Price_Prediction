House Price Prediction System

About the Project

This project is based on Machine Learning. It predicts the price of a house using different features like square feet, bedrooms, bathrooms, year built, and neighborhood.

In this project, I trained different machine learning models and compared their performance. After comparing the results, Linear Regression gave the best performance for this dataset.


Project Objective

- To predict house prices using machine learning.
- To learn data preprocessing and model training.
- To compare different regression models.
- To evaluate model performance using different metrics.


Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

Dataset

The dataset contains information about houses such as:

- Square Feet
- Bedrooms
- Bathrooms
- Year Built
- Neighborhood
- Price

The Price column is the target variable.


Models Used

- Linear Regression
- Decision Tree Regression
- Random Forest Regression


Evaluation Metrics

The models were evaluated using:

- MAE
- MSE
- RMSE
- R² Score


Best Model

After comparing all models, Linear Regression gave the best result for this dataset.


Future Improvements
